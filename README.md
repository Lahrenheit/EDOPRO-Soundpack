## 🛠️ Setup

in user_configs.json or configs.json write:

```
{
     			"url": "https://github.com/Lahrenheit/EDOPRO-Soundpack",
      		        "repo_name": "Lahrenheit EDOPro Soundpack",
     			"repo_path": "./sound/",
     			"should_update": true,
     			"should_read": true
},
```
